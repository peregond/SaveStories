# SaveMe — подготовка к macOS 27

Рабочая копия: `SaveMe-macOS27`, ветка `agent/macos-27-readiness`.
Основа: актуальная `main`, коммит `2299aa5`, версия 0.6.79.
Незавершённые изменения в `/Users/peregon/Documents/SaveStories` сохранены в исходной папке и в эту сборку не переносились.

## Что изменилось

- Сохранён фирменный SF Rounded; возвращён градиентный фон в светлой и тёмной темах. У карточек заметные границы, второстепенный текст контрастнее.
- Нативная боковая панель с возможностью скрыть её, системная панель инструментов и одно главное окно для общей очереди.
- Поле профилей и основная кнопка находятся в начале экрана. Статус, результаты и наборы — рядом в широком окне и ниже в узком.
- Прямой запуск из введённых профилей: они добавляются без дублей и не заменяются автоматическим списком Notion. Для запуска из Notion явно показано предупреждение о замене очереди.
- Параметры загрузки раскрываются по необходимости; переключатель очереди из Notion и кнопка обновления видны сразу. «Списочная» переименована в «Очередь профилей».
- ⌘1–4 переключают разделы, ⌘, открывает настройки, ⌘↩ запускает Stories, ⇧⌘O открывает папку сохранения.
- Диалог первого запуска и подтверждение очистки используют системные sheets с прокруткой и изоляцией фокуса. Удалена двойная рамка; кнопки первого запуска закреплены внизу. Закрытие системного диалога сохраняет выбор пользователя.
- Подписи для VoiceOver, различимые значки готовности, поддержка Reduce Motion / Reduce Transparency / Increase Contrast. Постоянный таймер свечения заменён системным эффектом.
- Исправлены освобождение фонового процесса, отмена операции и отправка запроса в завершившийся процесс. Некорректный ответ worker больше не попадает целиком в текст ошибки.
- Сборщик берёт ресурсы и Sparkle из точного каталога текущей release-сборки, проверяет комплектность и согласованность архитектур. SDK и минимальная macOS записываются по фактическим бинарникам.

## Воспроизведение

```sh
swift test
(cd node_worker && npm test)
python3 -m unittest discover -s scripts/tests -v
./scripts/build_beta_app.sh
python3 scripts/macos_bundle.py verify --app beta-build/release/SaveMe.app
```

Для проверки именно нового SDK: `SAVEME_REQUIRE_SDK=27 ./scripts/build_beta_app.sh`.
Команда отклонит установленный сейчас SDK 26.5, не маскируя его под 27.

Разработческий режим `--design-preview` отключает загрузчик/обновления и чтение сохранённых настроек. Для запуска QA-копии через Finder можно добавить только в её Info.plist `SaveMeDesignPreview = true` и заново подписать копию. Дополнительно `SaveMePreviewAppearance = light|dark`, `SaveMePreviewOnboarding = true`, `SaveMePreviewReduceMotion = true` помогают повторить UI-проверки без смены системных настроек. Эти ключи отсутствуют в передаваемой тестовой сборке.
