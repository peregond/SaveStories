## SaveMe 0.6.74

- macOS: видео Stories с раздельными Instagram DASH-потоками теперь сохраняются со звуком — H.264/HEVC-видео объединяется с AAC без перекодирования.
- macOS: встроенные файлы worker автоматически обновляются без сброса авторизации, Chromium и установленных зависимостей.
- macOS: старые video-only записи не считаются корректными дубликатами и могут быть повторно сохранены со звуком.
