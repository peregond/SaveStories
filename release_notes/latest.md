## SaveMe 0.6.86

Релиз для Windows. Выпуск для macOS не меняется.

- Новый клиент Windows на React и Tauri: быстрее запускается и заметно меньше нагружает компьютер, интерфейс в стиле macOS с полупрозрачным окном (Mica в Windows 11), светлой и тёмной темой.
- Сохранены все возможности прежнего клиента: Stories, «Списочная», Reels, сортировка по странам и блогерам, списки и правила из Notion, ссылки Google Drive, очистка пустых папок, вход в Instagram, обновления.
- Установщик ставится поверх прежней версии: настройки, правила сортировки и сессия Instagram сохраняются. Chromium докачивается при первом запуске, если его ещё нет.
- Исправлено отображение журнала выгрузки: длинные строки больше не растягивают окно.

Проверено автоматически: тесты интерфейса и бэкенда на Linux и Windows, установка поверх релиза 0.6.85, запуск воркера и приложения из установленной папки.
