## SaveMe 0.6.90

- **Новое имя скачанных файлов:** `дд.мм.гг-аккаунт-номер`, например `06.11.26-marco.vegas1-002.mp4` (Reels — `дд.мм.гг-аккаунт-reels-номер`). Дата — день скачивания, нумерация идёт заново каждый день отдельно для каждого аккаунта. Старые файлы не переименовываются; сортировка работает как раньше (аккаунт берётся из папки).
- **Убран раздел «Списочная»** (на macOS — «Очередь профилей»): профили вставляются и выгружаются на экране Stories, где уже есть очередь и параметры. На macOS сочетание ⌘3 теперь открывает «Сортировку».
- **Исправлена полоса справа у скачанных видео в плеере Windows.** Причина — флаг «в предпросмотре» в заголовках треков, который ставит Instagram: плеер Windows из-за него рисует полосу у вертикальных видео. Теперь воркер сбрасывает этот флаг у каждого скачанного видео (меняются два байта в файле, картинка и звук не затрагиваются; работает и на macOS). Уже скачанные файлы не меняются.
- **Windows:** плитки «Найдено» и «Сохранено» растут по ходу выгрузки (раньше стояли на 0 до самого конца); «Файлов» следует за живым счётчиком папки.
- **Windows:** строки в блоке «Очередь» больше не выходят за границы карточки в узком окне.
- Обновление с 0.6.89 пройдёт новым порядком: без запроса прав, с окном прогресса и автоматическим перезапуском (Windows).
