## SaveMe 0.6.72

- Windows: в настройках появилась включённая по умолчанию автоматическая смена оформления по времени суток, не зависящая от системной темы.
- Windows: светлая тема включается с 07:00 до 19:00, тёмная — с 19:00 до 07:00; автосмену можно отключить для ручного выбора.
- Stories: рядом со статусом «Загружаю» отображается анимированный индикатор работы, который исчезает после завершения операции.
