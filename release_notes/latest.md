## SaveMe 0.6.88

Релиз для Windows. Выпуск для macOS не меняется.

- **Меньше памяти у свёрнутого окна.** Когда окно свёрнуто, интерфейс отдаёт кэши, а если выгрузка не идёт и окно остаётся свёрнутым 20 секунд, замораживается; при разворачивании всё возвращается. На тестовой Windows рабочий набор свёрнутого окна падает примерно с 340 до 50 МБ (частная память почти не меняется: около 120 → 113 МБ). Во время выгрузки интерфейс не замораживается.
- Развёрнутое окно по памяти не изменилось: у клиента на WebView2 это порядка 120 МБ частной памяти против примерно 70 МБ у прежнего WinUI-клиента.
- Проверка на Windows теперь включает цикл «свернуть → развернуть» и убеждается, что интерфейс отвечает.

Автообновление с 0.6.87 установит эту версию само.
