## SaveMe 0.6.89

Релиз для Windows. Выпуск для macOS не меняется.

- **Автообновление изнутри приложения стало аккуратнее.** Установщик больше не просит права администратора (он ставится в профиль пользователя и раньше запрашивал их зря — а у обычной учётной записи мог поставиться не туда). Обновление идёт в тихом режиме с окном прогресса, приложение закрывается само и запускается снова уже новой версией.
- Обновление нельзя запустить во время выгрузки: кнопка недоступна, пока идёт работа.
- Полный путь обновления (поиск → скачивание с проверкой SHA-256 → установка → перезапуск) теперь проверяется на Windows при каждой сборке.

Важно: сама эта версия ставится по-старому из 0.6.87/0.6.88 (с запросом прав и обычным окном установщика) — новый порядок начнёт работать со следующего обновления.
