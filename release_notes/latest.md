## SaveMe 0.6.76

- macOS и Windows: активные Stories теперь сначала получаются через Instagram API и больше не зависят от кружка профиля или текущей разметки страницы.
- Если API временно недоступен, приложение автоматически использует прежний сценарий открытия Stories в браузере.
- Исправление видео без звука из 0.6.75 сохранено: раздельные H.264/HEVC + AAC потоки объединяются без перекодирования на обеих платформах.
