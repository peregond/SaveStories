## SaveMe 0.6.81

- Новая адаптивная иконка macOS из оригинального проекта Icon Composer: градиент, стеклянные эффекты, тёмное и тонированное оформление.
- Сохранены слои и настройки исходника; иконка компилируется в Assets.car для системных режимов оформления.
- Релизная сборка останавливается, если Icon Composer не удалось скомпилировать, вместо подстановки старой статической иконки.
