## SaveMe 0.6.96

- **macOS:** новый дизайн в стиле Liquid Glass для macOS 26 и 27: стеклянные панели, единые кнопки-капсулы, спокойный фон; на macOS 14–15 и при «Уменьшении прозрачности» — плотные поверхности.
- **macOS:** Уникализатор разбит на шаги: исходники, плашка 18+, формат, название файла, стиль, дополнительно, запуск. Стили выбираются карточками, перед запуском показывается сводка настроек, шаги с ошибкой отмечены.
- **Уникализатор:** из онлайн-сервиса перенесены яркость, контраст и отражение по горизонтали (на macOS; в интерфейсе Windows появятся позже). На macOS добавлен предпросмотр первого исходника.
- **macOS:** прогресс загрузки виден из любого раздела: счётчик в боковой панели, индикатор в панели инструментов, число оставшихся профилей на значке в Dock; по завершении приходит уведомление.
- **macOS:** очередь Stories стала компактнее, пустые панели не занимают место, «Удалить пустые папки» вынесено из шагов сортировки, очистка очереди и удаление папок спрашивают подтверждение.
- **macOS:** тексты приведены к единому обращению на «вы».
