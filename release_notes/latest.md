## SaveMe 0.6.79

- Исправлена неполная выгрузка Stories, когда Instagram ограничивает запрос профиля ответом `429`: worker берёт numeric `pk` из уже загруженных данных страницы и получает полный reel-плейлист без повторного profile lookup.
- Для reel endpoint теперь используется Instagram `pk`, а не несовместимый Graph API `id`.
- Резервный обход Story viewer отличает видео от poster-изображения и надёжнее переходит ко всем следующим историям.
