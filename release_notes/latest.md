## SaveMe 0.6.80

- Обновлён интерфейс macOS: фирменный SF Rounded, читаемый градиентный фон и нативная боковая панель.
- Исправлена двойная рамка первого запуска; кнопки доступны при прокрутке.
- Очередь Notion управляется видимым переключателем без раскрывающегося раздела.
- Введённые профили запускаются напрямую, без дублей и неожиданной замены списком Notion.
- Добавлены сочетания клавиш, улучшены контрастность и поддержка системных настроек доступности.
- Исправлены отмена и повторный запуск фоновых операций; усилена проверка упаковки приложения.

Проверены запуск и 46 Swift-тестов на macOS 27.0 (26A428), Apple Silicon. Минимальная версия системы остаётся macOS 14. Локальная проверка выполнена с SDK 26.5; полноценные сетевые загрузки Instagram и повторная проверка на macOS 14 в этот цикл не входили. Сборка распространяется с ad-hoc подписью, без Developer ID и нотариализации, как предыдущие версии.
