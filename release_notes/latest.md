## SaveMe 0.6.69

- macOS: убрана дублирующая верхняя строка состояния; индикаторы Node и Session, проверка среды и вход перенесены в карточку «Состояние».
- macOS: номер версии оставлен только в нижней части боковой панели, а пункт «Настройки» теперь отображается без дополнительной подписи.
- macOS: системная строка заголовка встроена в интерфейс; подложка и разделитель боковой панели занимают всю высоту окна.
- macOS: приложение по умолчанию проверяет и скачивает обновления в фоне при запуске.
- macOS: после скачивания, проверки подписи и подготовки пакета над номером версии появляется кнопка «Обновить».
- macOS: добавлен тумблер автоматических обновлений и точные состояния проверки, загрузки, готовности и ошибки Sparkle.
- Stories: блоки «Состояние» и «Результат» сохраняют одинаковую высоту, а служебные действия больше не дублируют текущий статус.
